# Contributing — Sentinel Node Wallet BTCB2

This is a standalone Apple Silicon/macOS SwiftUI application for the BTCB2 BLAKE2b/BIP-110 MainNet and a local Bitcoin Knots node. Read [Governance](GOVERNANCE.md), [Security](SECURITY.md), [Current Status](docs/PROJECT_STATUS.md), [Architecture](docs/ARCHITECTURE.md) and [Release Matrix](TEST_AND_RELEASE_MATRIX.md) before editing.

- **Branching:** Work from fresh `main` in a reviewed PR. Historic [PR #10](https://github.com/PeterJFrancoIII/sentinel-node-wallet-btcb2/pull/10) was merged; the Build 3 release has already been [published on GitHub](https://github.com/PeterJFrancoIII/sentinel-node-wallet-btcb2/releases/tag/v1.0.0-build3).
- **Scope:** Change only this project's code, test fixtures and docs. No data, secrets or runtime coupling to unrelated services. The consumer app is MainNet-only; ephemeral regtest is for isolated tests.
- **Preserve user state:** No unapproved manipulation of existing wallets, Keychain, blockchain data, daemon PID, synchronization, or backups. Do not run full uninstall/wipe as a development cleanup. Use temporary, zero-funds datadirs and fixture accounts.
- **Spend and delete controls:** RPC send/broadcast restriction defaults enabled and must not be disabled without independent fork-specific security signoff; current individual-wallet Delete has an unconditional no-restore-proof stop. A feature implementation or passing unit test is not authorization for funded sends or destructive operations.
- **Tests:** Run `swift test`, applicable isolated Knots regtest tests, `python3 tools/verify_governance.py`, `bash scripts/secret_scan.sh`, and any platform-specific native tests for touched features. Report executed/passed/failed/skipped separately, exact SHA and CI URL. Latest verified baseline before this refresh: [CI #43663913374](https://github.com/PeterJFrancoIII/sentinel-node-wallet-btcb2/actions/runs/43663913374), 144 executed / 143 passed / 0 failed / 1 skipped.
- **Packaging:** GitHub Build 3 has a published DMG and checksum; its existence does not verify Developer ID notarization. Distinguish dev DMG, App Store candidate, Apple distribution processing and security-certified release. Follow [Release Checklist](docs/PRODUCTION_RELEASE_CHECKLIST.md).
- **Handoffs:** Follow the [Shared Cognitive Memory rules](https://github.com/PeterJFrancoIII/Shared-Cognitive-Memory-for-Cross-Platform-AI-Conversations/tree/main/docs/SHARED_MEMORY_AGENT_RULES.md) and cite the canonical session `Session_Gemini_NodePocketBTCB2_20261106-1741`. Never commit secrets or personal wallet records.

**Release policy:** Documentation and CI may be merged after normal review, but changes that enable funded transactions, broad deletion, privileged access or public distribution require separate affirmative safety acceptance.
